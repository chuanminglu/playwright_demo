## 测试方法论应用

### 等价类划分
- **有效等价类**：
  - 用户名：已注册的有效用户名（kongguan）
  - 密码：与用户名匹配的正确密码（kongguan1qaz@WSX）
  - 验证码：当前页面显示的正确验证码（4-6位数字/字母）
  
- **无效等价类**：
  - 用户名：空值、未注册用户名、特殊字符、SQL注入字符
  - 密码：空值、错误密码、特殊字符
  - 验证码：空值、错误验证码、过期验证码、大小写错误

### 边界值分析
- **用户名长度**：假设限制3-20字符，测试边界值2、3、20、21
- **密码长度**：假设限制6-20字符，测试边界值5、6、20、21（推断，需与开发确认）
- **验证码长度**：假设固定4位，测试3位、4位、5位

### 场景法
- **正常场景链路**：
  1. 访问登录页 → 查看验证码 → 输入正确凭证 → 点击登录 → 跳转到首页
  
- **异常场景链路**：
  1. 输入错误凭证 → 点击登录 → 显示错误提示 → 停留登录页
  2. 多次登录失败 → 账号锁定（推断，需与安全策略确认）
  3. 验证码过期 → 刷新验证码 → 重新输入

### 错误推测法
- **常见操作失误**：
  - 重复快速点击登录按钮（防抖测试）
  - 密码输入错误后，密码框应清空但用户名保留
  - 浏览器后退键返回登录页的状态
  - 网络中断时提交登录请求
  - 会话超时后刷新页面

## 自动化测试建议

### 验证码处理方案（按优先级）

#### 方案1：测试环境Mock接口（⭐⭐⭐⭐⭐ 强烈推荐）
**实现方式**：后端提供测试专用接口 `/api/test/captcha`，返回当前Session的验证码值
```javascript
// Playwright 代码示例
const captcha = await page.evaluate(() => {
  return fetch('/api/test/captcha').then(r => r.json()).then(d => d.captcha);
});
await page.fill('[data-test="captcha"]', captcha);
```
**优点**：准确率100%，速度快，稳定性高  
**要求**：需要后端开发提供测试接口

#### 方案2：测试环境固定验证码（⭐⭐⭐⭐ 推荐）
**实现方式**：测试环境配置固定验证码（如"1234"）
```javascript
// Playwright 代码示例
await page.fill('[data-test="captcha"]', '1234');
```
**优点**：实现简单，手工测试也方便  
**要求**：需要后端配置 `application-test.yml` 中 `captcha.fixed-value=1234`

#### 方案3：OCR识别验证码（⭐⭐ 备选方案）
**实现方式**：使用 tesseract.js 识别验证码图片
```bash
npm install tesseract.js
```
```javascript
// Playwright 代码示例
import Tesseract from 'tesseract.js';

const captchaImage = await page.locator('[data-test="captcha-image"]');
const screenshot = await captchaImage.screenshot();
const { data: { text } } = await Tesseract.recognize(screenshot, 'eng');
const captcha = text.trim().replace(/\s/g, '');
await page.fill('[data-test="captcha"]', captcha);
```
**缺点**：准确率不稳定（60-80%），执行慢（1-3秒/次）  
**适用场景**：无法修改后端时的临时方案

### 推荐实现（组合方案）
```javascript
// helpers/captcha.ts
export async function getCaptcha(page: Page): Promise<string> {
  try {
    // 优先尝试Mock接口
    return await page.evaluate(() => {
      return fetch('/api/test/captcha')
        .then(r => r.json())
        .then(d => d.captcha);
    });
  } catch (e) {
    // 降级到固定验证码
    console.log('使用固定验证码：1234');
    return '1234';
  }
}

// 测试用例中使用
const captcha = await getCaptcha(page);
await loginPage.fillCaptcha(captcha);
```
